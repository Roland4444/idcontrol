# Контроль ИД v0.6.7.4 — восстановление сессии Synology

Ошибка `Synology scan failed: ... (code Some(119))` означает **недействительную сессию File Station (SID)**.

Изменения:
- Вместо обработки ошибки 119 как безусловного сбоя сканер переподключается к DSM и повторяет обход с корня.
- Повторяет до 3 попыток на коды DSM 106 (timeout), 107 (duplicate login/interrupted) и 119 (invalid SID).
- Выводит в терминал предупреждение о повторном входе и запись об успешном восстановлении.
- При окончательном сбое сообщает об ошибке, **не отмечая документы удалёнными**, пока не завершит полный обход NAS.
- Не меняет миграции БД, OCR, имена каталогов, конфигурацию или проверку APP_PASSWORD (от 3 байт).

Проверка:

```powershell
cargo check
cargo test
cargo run -- --check-synology
cargo run
```

Для работающего проекта перенесите существующий `.env` и сохраните `DATA_ROOT` и `models/ocr`.

Если код 119 систематически повторяется даже после переподключения, проверьте одновременные входы от имени того же пользователя File Station, DSM Login log и источники сетевых запросов.

Полная компиляция и соединение с реальным NAS в среде создания этого архива не выполнялись.

# Локальный нейросетевой OCR — Контроль ИД v0.6.7

## Что добавлено

Полноценный локальный OCR с распознаванием кириллицы: Rust `rapidocr-core 0.2.2` + ONNX Runtime + модели PaddleOCR PP-OCRv5 (детектор текста, восточнославянская модель распознавания, UTF-8 словарь). Для PDF уже используемый Hayro рендерит страницы в изображения, которые передаются в локальные ONNX-сессии. Модели и вычисление работают локально. Tesseract и pdftoppm не нужны, VibeCode для режима `local` не нужен. DOCX/XLSX по-прежнему читаются локальными парсерами без OCR.

## Установка в Windows

1. Остановить текущий процесс сервера `Ctrl+C`. Распаковать v0.6.7, перенести прежний `.env` в корень новой папки (оставить DATA_ROOT, DATABASE_URL и все Synology-параметры без изменений).
2. Добавить в `.env`:

```dotenv
OCR_MODE=local
LOCAL_OCR_MODEL_DIR=./models/ocr
OCR_MAX_PAGES=500
OCR_PAGE_WORKERS=6
VIBE_OCR_ENABLED=false
```

3. Из PowerShell в корне проекта скачать веса нейросети (примерно 96 МБ, скачиваются один раз):

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-local-ocr-models.ps1
```

4. Собрать и проверить:

```powershell
cargo check
cargo test
cargo run -- --check-local-models
cargo run -- --check-ocr "tests\fixtures\test_2_pages.pdf"
```

5. Если все нормально, запустить `cargo run`, открыть `/diagnostics` и запустить «Распознать все с ошибками». Если нужно переобработать все файлы — «Перераспознать весь комплект». Для отдельного файла предусмотрена «Повторить OCR».

ONNX Runtime может потребовать актуальные библиотеки Microsoft Visual C++ Redistributable (Windows). Если Cargo не может скачать зависимости, потребуется доступ к crates.io или настроенному зеркалу. Сами модели скачиваются с Hugging Face скриптом отдельно; сетевой доступ нужен только при установке, не для распознавания.

## Режимы

- `OCR_MODE=local` — только локальная нейросеть. Документы не покидают сервер.
- `OCR_MODE=vibecode` — только внешний Bitrix VibeCode, как в v0.6.6.
- `OCR_MODE=local_then_vibecode` — использовать локальную модель; при ошибке и отсутствии текста перейти к VibeCode. В этом режиме нужно дополнительно установить `VIBE_OCR_ENABLED=true` и `VIBE_OCR_KEY`. Внешние вызовы разрешайте только с учётом политики обработки данных.

**Важно:** `AI_MODE=off` не отключает OCR; OCR_MODE — отдельный параметр.

## Производительность и ограничения

Для PDF ONNX-сессия создаётся один раз **на поток**. До `OCR_PAGE_WORKERS` страниц распознаются параллельно, а готовый текст сортируется по исходным номерам страниц. PDF-страницы рендерятся потоком в ограниченную очередь (не более двух ожидающих изображений на каждый OCR-поток), поэтому все страницы PDF не копятся в оперативной памяти. Консоль, журнал PostgreSQL и `/diagnostics` показывают подготовку, активность потоков, число завершённых страниц, скорость в страницах/мин и ошибки. 

`OCR_PAGE_WORKERS=6` означает до шести одновременных экземпляров ONNX-модели. Это не ограничение внутренних вычислительных потоков ONNX Runtime — каждый экземпляр может дополнительно использовать ядра CPU. При 6 физических ядрах сравните `OCR_PAGE_WORKERS=3` и `6` и выберите по фактической скорости и потреблению RAM. У каждого потока своя копия моделей, поэтому расход памяти возрастает.

- Требуется CPU/RAM; первая загрузка ONNX-моделей может занять время, большой PDF дольше. Скорость зависит от компьютера.
- OCR не означает юридическую/нормативную проверку и не гарантирует точное чтение таблиц и подписей.
- Встроенный декодер TIFF сейчас обрабатывает первый кадр и помечает многостраничный TIFF как `partial` для проверки человеком.
- По `OCR_MAX_PAGES` лишние PDF-страницы пропускаются с `partial`, а не выдаются за полностью распознанные.
- Модель хранится вне ZIP и скачивается отдельно. Имеющиеся оригиналы и записи БД не удаляются.
- Для распознавания документов с низкой оценкой confidence требуется проверка человеком. Баллы confidence оценочные.

## Источники весов

PaddleOCR модели (Apache-2.0): https://huggingface.co/monkt/paddleocr-onnx .
Файлы: `detection/v5/det.onnx`, `languages/eslav/rec.onnx`, `languages/eslav/dict.txt`. Скрипты сверяют SHA-256 для ONNX файлов. Веса не включены в исходный ZIP, поскольку это ~96 МБ сторонних бинарных данных.

## Проверка конфигурации

```powershell
cargo run -- --ocr-status
```

API `/api/ocr/status` также показывает `ocr_mode`, директорию моделей и `local_models_ready`.

## Как вернуться к VibeCode

В `.env`: `OCR_MODE=vibecode`, `VIBE_OCR_ENABLED=true` и твой `VIBE_OCR_KEY`. Перезапустить приложение. Уже зарегистрированные документы не требуют повторной загрузки с NAS — через веб запускается повторная обработка.

## Статус качества сборки

В среде генерации архива отсутствует Rust toolchain и нет доступа к crates.io/Hugging Face: компиляция, реальные ONNX инференсы и загрузка моделей НЕ были проверены. Код написан на основе публичной документации API `rapidocr_core` v0.2.2. Сначала выполните `cargo check`, затем тест.

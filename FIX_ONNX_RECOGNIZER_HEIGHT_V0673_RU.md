# Контроль ИД v0.6.7.3 — исправление размерности модели распознавания

Исправлено: `src/local_ocr.rs`, у рекогнайзера PP-OCRv5 (eslav `rec.onnx`) высота входа **48**, а не 32 пикселя.

Было: `rec.image_shape=[3,32,320];`
Стало: `rec.image_shape=[3,48,320];`

Это устраняет ошибку ONNX `Got invalid dimensions for input: x ... index: 2 Got: 32 Expected: 48`, которую вы прислали. Остальные настройки модели и очереди OCR не изменялись.

## Обновление на Windows

1. Остановите приложение (`Ctrl+C`).
2. Если переносите полный архив — скопируйте собственный `.env`, папку `models/ocr` и, если потребуется, локальный каталог хранения оригиналов из старой установки. Не заменяйте/не удаляйте существующую PostgreSQL.
3. В корне проекта выполните:

```powershell
cargo check
cargo run -- --check-local-models
cargo run -- --check-ocr "tests\fixtures\test_2_pages.pdf"
cargo run
```

4. В веб-интерфейсе повторите OCR документа с ошибкой. Если файл уже находится в очереди, дождитесь завершения/повторно поставьте после ошибки.

Доработка не требует повторного скачивания ONNX-моделей или SQL-миграций. Локальные модели должны быть установлены из вашего предыдущего окружения.

## Ограничение проверки

ZIP проверен структурно. Компиляция и реальный ONNX inference в среде подготовки архива не запускались (нет Rust toolchain и моделей). Успех в вашем окружении подтвердится только после `cargo check` и реального OCR-теста.

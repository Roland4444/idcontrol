# Исправление сборки OCR (v0.6.7.2)

Ошибка Windows `rapidocr-core-0.2.2/src/inference.rs:32`: `Session::builder()` вызывается без аргументов, но `ort-2.0.0-rc.14` требует `&Environment`. Это несовместимость релизов.

Исправление: в `Cargo.toml` добавлена **строгая** зависимость `ort = "=2.0.0-rc.12"`, соответствующая API rapidocr-core 0.2.2. Другие модули, OCR-модели, SQL-миграции, Synology и конфигурация не менялись.

Выполнить в PowerShell из каталога проекта:

```powershell
cargo update -p ort --precise 2.0.0-rc.12
cargo tree -i ort
cargo check
cargo test
cargo run -- --check-local-models
```

Если Cargo выведет ошибку в ходе обновления, пришлите вывод. Подтвердить компиляцию в среде подготовки архива было невозможно: Rust/Cargo здесь не установлены.

Перенесите свой `.env` из прежнего проекта. Не копируйте файлы `target` или чужой `Cargo.lock`: лучше использовать lock-файл, созданный в вашей среде.

Пароль по-прежнему проверяется по `password.len()<3`; требование 16 символов не возвращено.

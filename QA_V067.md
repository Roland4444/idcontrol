# QA — v0.6.7

Проверено: наличие исходников v0.6.6, сохранение 6 миграций, корректная конфигурация Cargo TOML, наличие модулей локального OCR, обработка режимов `OCR_MODE`, управление очередью, целостность ZIP, ссылки на скрипты скачивания моделей, `bash -n` для Linux скрипта. `APP_PASSWORD` по-прежнему проверяется от 3 байт, `password.len()<3`.

**Не проверено**: `cargo check`, `cargo test`, запуск ONNX-моделей на Windows/Ubuntu и реальная точность распознавания — в текущем окружении нет Rust/Cargo и закрыт интернет. Веса ONNX НЕ включены в ZIP. Локальную работоспособность следует подтвердить после установки моделей и запуска тестового PDF, до массовой обработки Synology.

Модель взята из репозитория [monkt/paddleocr-onnx](https://huggingface.co/monkt/paddleocr-onnx), лицензия Apache-2.0; источник RapidOCR Rust — [rapidocr-core 0.2.2](https://docs.rs/rapidocr-core/0.2.2/rapidocr_core/). Для установки весов используются scripts/install-local-ocr-models.ps1/.sh, SHA-256 контролируется для det.onnx и rec.onnx.

**Обновление существующей БД:** новые миграции не нужны. Предыдущие статусы ошибок остаются до ручной повторной обработки. Старый `.env` перенести из существующей системы и установить OCR_MODE=local, VIBE_OCR_ENABLED=false; существующий DATA_ROOT, DATABASE_URL и параметры Synology оставить прежними.
